LASERcoder help window text
===========================

Each .md file here is one tab of the in-app help window (the "?" button,
or F1). Edit these files to change the help text; no code changes are
needed. They are plain Markdown as rendered by Qt (GitHub dialect:
headings, lists, tables, **bold**, `code`, links).

  getting_started.md      Getting Started tab
  annotating.md           Annotating tab
  files_and_analysis.md   Files and Analysis tab

The Keyboard Shortcuts tab is generated in src/help_dialog.py, because it
shows the current settings and the keys loaded for the open video.

Placeholder replaced when the window opens:
  {MOD}   Ctrl on Windows and Linux, Cmd on macOS

The full documentation is README.md in the repository root. Keep the two
consistent when a feature changes.
